## Что реализовано
1. **Задание 1 (Создание потоков):** Созданы два потока. `EvenThread` наследует `Thread` и выводит четные числа, `OddRunnable` реализует `Runnable` и выводит нечетные числа. Запуск происходит через `start()`, потоки работают асинхронно.
2. **Задание 2 (Producer-Consumer):** Реализован склад `ShoeWarehouse` с ограниченной очередью (на 5 заказов). Используются блоки `synchronized`, а также методы `wait()` и `notifyAll()` для синхронизации потоков. Один Producer генерирует 10 заказов, два Consumer'а обрабатывают их по FIFO.
3. **Задание 3 (ExecutorService):** Модифицирована работа склада через пулы потоков. В `main` используются `Executors.newSingleThreadExecutor()` для генерации заказов и `Executors.newFixedThreadPool(2)` для их обработки. Очередь реализована через `BlockingQueue`.

## Команды сборки и запуска
1. Сборка проекта: `mvn clean package`
2. Запуск демонстрации: открыть класс `app.Main` в IDE и запустить метод `main()`.
